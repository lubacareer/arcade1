# Asset provenance

All starfields, paddles, ships, arena diagrams, trails, particles and interface geometry are original procedural artwork drawn by the game code.

The WAV files are original mathematical synthesis, generated by `generate_assets.py`. No external audio samples or generation service are used. The ambient loop uses integer-period oscillators.

The body atlas uses 48px glyphs on a 1024px texture; the display atlas uses 96px glyphs on a 2048px texture for sharp titles. Both retain their original logical text sizes.

Bitmap font atlases are rendered from DejaVu Sans and DejaVu Sans Bold, obtained from the installed matplotlib distribution. Their redistribution license is preserved in `fonts/LICENSE_DEJAVU`. No proprietary system fonts are bundled. To reproduce, install Pillow and pass a directory containing the DejaVu TTF files and license:

```
python assets/generate_assets.py --font-dir /path/to/dejavu/fonts
```

All generated assets ship in the application; no content is downloaded at runtime.
